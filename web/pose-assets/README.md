# Bundled pose runtime

MediaPipe Tasks Vision 0.10.32 files from https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.32/ (vision_bundle.mjs and wasm/*).

Pose Landmarker Lite float16 model version 1 from https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task .

Apache 2.0 license included. These assets are served locally with the application so camera inference does not require a CDN at runtime. No captured images are uploaded by this runtime.
